# BreastCancer_KNN
📌 Project Overview

This project implements the K-Nearest Neighbors (KNN) algorithm to predict whether a breast cancer tumor is Benign or Malignant based on medical diagnostic features. KNN is a simple yet powerful supervised machine learning algorithm that classifies data points based on the similarity of their nearest neighbors.

The project demonstrates the complete machine learning pipeline, including data preprocessing, model training, prediction, and performance evaluation. KNN is commonly used in healthcare-related classification problems because of its effectiveness and interpretability.

🎯 Objectives
Build a breast cancer classification model using KNN.
Preprocess and analyze the dataset.
Train and test the machine learning model.
Evaluate classification performance.
Understand how KNN works in real-world healthcare applications.

🧠 About K-Nearest Neighbors (KNN)

K-Nearest Neighbors is a supervised machine learning algorithm used for classification and regression tasks. It classifies new data points by finding the K nearest neighbors in the training dataset and assigning the most common class among them.

Advantages

✅ Simple and easy to understand

✅ No training phase required

✅ Effective for classification tasks

✅ Works well with smaller datasets

✅ Easy to implement and visualize
